# Mutual Fund Analytics Capstone Project

## Project Overview

This project analyzes mutual fund industry data using Python, SQL, and Power BI. The objective is to perform ETL, exploratory data analysis, fund performance analytics, risk analysis, and dashboard development.

## Technologies Used

* Python
* Pandas
* NumPy
* SQLite
* SQLAlchemy
* Matplotlib
* Seaborn
* Plotly
* Power BI

## Project Structure

* data/raw
* data/processed
* scripts
* notebooks
* reports
* sql
* dashboard

## Setup

pip install -r requirements.txt

## Run ETL

python scripts/data_cleaning.py

## Load Database

python scripts/load_to_sqlite.py

## Run EDA

python scripts/eda_analysis.py

## Run Performance Analytics

python scripts/performance_analytics.py

## Run Advanced Analytics

python scripts/advanced_analytics.py

## Dashboard

Open bluestock_mf_dashboard.pbix using Power BI Desktop.
